# 🔧 RACE DAY FORMAT

Every day follows the same race procedure:

### 🟢 1. WARM-UP

Review one previously solved problem.

### 🟡 2. QUALIFYING

Read the problem carefully.

Identify:

- Input
- Output
- Constraints
- Examples
- Possible patterns

### 🔴 3. MAIN LAP

Attempt the problem independently.

No solution immediately.

### 🛠️ 4. PIT WALL

If stuck:

**Hint 1 → Concept**

↓

**Hint 2 → Approach**

↓

**Hint 3 → Specific direction**

↓

**Solution only if explicitly requested**

### 📊 5. TELEMETRY

Record:

- Approach
- Time Complexity
- Space Complexity
- Mistakes
- Optimization

### 🏁 6. FINISH LINE

Submit to LeetCode.

Then update:

- README
- Java file
- GitHub commit
